# ابدأ من هنا — ثرى بعد إعادة البناء

هذه هي النسخة الحالية. احتفظنا بملفات كلود والنسخة السابقة في archive/. المجلد thara-water-rebuild ليس النسخة المعتمدة.

## التجربة

- رابط النسخة الجديدة: https://mutasem-mk4.github.io/thara-demo/
- الإنجليزية: https://mutasem-mk4.github.io/thara-demo/?lang=en
- الرابط القديم على Sites يعرض نسخة سابقة؛ لم نتمكن من تحديثه بسبب عدم توفر صلاحية المشروع في الاتصال الحالي.
- اضغط «شوف مثال دير علا»، وقارن الكوسا والبندورة. جرّب إضافة الثلاثاء، واسترجع البداية، ثم أخّر خيارًا أسبوعين.
- افتح «كيف حسبناها؟» لتتبع رقم إلى بيانات NASA. احفظ الخطة PDF أو نزّل ملف التتبع.
- بعد النتائج، غيّر أولوية المراجعة لتقديم أسئلة الماء أو التربة أو المخاطر؛ الأرقام تبقى ثابتة. القيود الإضافية اختيارية وتصل للطباعة وملف التدقيق.
- افتح «دليل محلي» لمقارنة الأعلاف المستقلة: خط أساس غير معروف، وسورغم ثم بيقية، وسيسبانيا ثم شعير. غيّر أولويتها إلى استمرارية العلف. اتركها مفتوحة عند الطباعة لإضافتها، أو مغلقة لخطة الخضار وحدها.
- للتشغيل من مجلد thara: npm ci ثم npm run dev. لا يوجد API key مطلوب.

## ماذا أُنجز؟

- مسار واحد: الأرض ← الماء ← خيارات الزراعة ← المقارنة.
- مصدر NASA حقيقي محفوظ لعشر سنوات، وجلب مباشر للموقع مع فشل صادق وبديل مطابق.
- تقدير FAO للاستـهلاك يتغير بالمحصول والتاريخ. المقارنة تتغير بالأيام والكمية والمساحة.
- سبعة محاصيل بنموذج؛ البامية والمحصول غير المحدد للطقس فقط لعدم التحقق من معاملات مكتملة.
- عربي/إنجليزي، رسم أسبوعي، تجارب قابلة للاسترجاع، PDF وملف تدقيق.
- 50 اختبارًا ناجحًا وbuild ناجح وفحوص متصفح. السجل: ../docs/VALIDATION.md.
- القياسات والملاحظات تميّز عدم الإدخال والمجهول وما يذكره المستخدم. اكتمال التوثيق لا يثبت القياس، ولا يدخل ECw/ECe حساب الاستهلاك.
- نص التقديم والعرض والتسجيل وأسئلة الحكام محدثة. استخدم شرائح THARA_Final_EN الموجودة في هذا المجلد؛ الشرائح الأقدم تخص نطاقًا سابقًا. المواد والشرائح العامة: https://mutasem-mk4.github.io/thara-demo/materials/

## ماذا بقي للفريق؟

- تجربة النسخة والتدرّب على السيناريو في DEMO_RECORDING.md.
- التأكد من تسجيل الأعضاء الستة وحالة الفريق في المنصة.
- التحقق من POWER في موارد التحدي والقطع المحلي وحقول التقديم الفعلية؛ ما زالت غير محسومة.
- مراجعة نص SUBMISSION_EN.md والروابط والشرائح ثم التقديم رسميًا من حساب الفريق.
- لا توجد مقابلات أو مزرعة مقاسة أو تحقق زراعي أو أثر مثبت. لا تحكوا إن النسبة تثبت كفاية الري أو وفر الماء.

النسبة مقارنة استكشافية بين الماء المدخل واستهلاك مقدّر، وليست وصفة ري. التواريخ ومساحة وكمية المثال افتراضية، والطقس حقيقي تاريخي شبكي.
